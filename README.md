# Encoding Converter v2

研究室などから受け取った「文字コードが混在したフォルダ」を、
ファイル拡張子に頼りすぎず、中身を見て変換する個人用GUIツールです。

## 想定用途

### MATLAB
フォルダ内を丸ごと走査します。

- `.m` だけに限定しません
- `.dat`, `.txt`, `.c`, 拡張子なしスクリプトなども「テキストなら」対象
- `.mat`, `.fig`, `.o`, `.ko`, 実行ファイルなどバイナリは自動スキップ
- 出力: CP932
- ユーザー環境の MATLAB R2007b (`DefaultCharacterSet = Shift_JIS`) 向け

### Unix C
こちらもフォルダ内を丸ごと走査します。

- `.c`, `.h` だけに限定しません
- Makefile / シェルスクリプト / `.m` / `.dat` などもテキストなら対象
- バイナリは自動スキップ
- 出力: UTF-8 BOMなし

### Custom
- 入力文字コードを Auto / 手動指定
- 出力文字コードを自由指定
- 読み取り前後のプレビュー
- 候補エンコーディング表示
- 必要なら拡張子フィルタも使用可能

## フォルダ変換時

上書きOFFの場合、保存先フォルダに元の構造をコピーします。

- テキスト → 文字コードを変換して保存
- バイナリ → そのままコピー
- 自動判定不能 → そのままコピー

そのため、変換後フォルダだけで元プロジェクトの構造を保てます。

## 単一ファイル

ファイルを1つだけD&Dした場合は、
「変換して保存」で通常の「名前を付けて保存」になります。

## 起動

Python 3.8 + PySide2 を想定しています。

```bat
py -m pip install -r requirements.txt
python main.py
```

既にPySide2を入れている場合は、そのまま:

```bat
python main.py
```

## 重要

文字コードの自動判定には原理的に100%の正解はありません。
特に短い日本語ファイルでは CP932 / Shift_JIS / EUC-JP の判別が曖昧な場合があります。

怪しい場合は Custom モードでプレビューしてください。

また、MATLABモードでCP932に存在しない文字を含むUTF-8ファイルを変換すると、
勝手に文字を捨てず「変換失敗」にします。


## v3

- GUI全体のフォントを12ptに拡大
- ファイル一覧の行高も拡大
- フォルダを投入した場合、保存先を毎回選ばず
  `元フォルダ名_encoded` を同じ場所に自動作成
- フォルダ内部のファイル名には `_encoded` を付けない
- 単一ファイル変換でも `_encoded` は自動付与しない

例:

```text
C:\work\to_nishiwaki\
  main.m
  goto\foo.c

↓ 変換

C:\work\to_nishiwaki_encoded\
  main.m
  goto\foo.c
```


## v4

「変換できないファイルも元のままコピー」をデフォルトONにしました。

フォルダ一括変換時、このチェックがONなら、
バイナリ・自動判定不能・出力文字コードへ変換不能のファイルも
元の内容のまま出力フォルダへコピーします。


python -m PyInstaller --clean --noconfirm --onefile --windowed --icon=app.ico --name=EncodingConverter main.py
